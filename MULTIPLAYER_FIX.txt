CHANGES MADE:

2. Player Connection Fix:

   - Updated game over messages to say "Team Victory!" / "Team Eliminated!"
   - Emphasized it's a cooperative game

HOW IT WORKS NOW:
-----------------
1. Host creates room → Immediately sees waiting room
2. Player joins room → Sends 'request_state' to host
3. Host receives request → Broadcasts current game state
4. Player receives state → Shows waiting room with players list
5. Both players can set bets and ready up
6. Game starts when all players ready

GAME MECHANICS (Already Correct):
----------------------------------
- Turn-based: Players take turns clicking cells
- Team game: If ANY player hits a mine, game ends with winner=false
- Everyone loses their bet if mine is hit
- Everyone wins (bet × multiplier) if all safe cells revealed
- Multiplier increases as more cells are revealed (1x → 3x)
