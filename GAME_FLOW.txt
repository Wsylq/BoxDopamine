MULTIPLAYER GAME FLOW
=====================

CONNECTION FLOW:
----------------
HOST:
1. Click "Host Game" → Creates room (e.g., GMF7Z8)
2. Immediately sees: Waiting Room with game rules
3. Shares Room ID with friends
4. Waits for players to join

PLAYER:
1. Click "Join Game" → Enter Room ID
2. Connects to server
3. Sends 'request_state' to host
4. Receives game state from host
5. Sees: Waiting Room with all players

GAME SETUP:
-----------
1. Each player sets their bet amount (min $10)
2. Each player clicks "Ready!"
3. When ALL players ready → Host starts game
4. Grid appears (5×5 with 6 mines)

GAMEPLAY (TEAM MINESWEEPER):
-----------------------------
Turn Order: Player 1 → Player 2 → Player 1 → ...

Each Turn:
- Current player clicks a cell
- If SAFE: Cell reveals number (adjacent mines)
  → Multiplier increases
  → Next player's turn
  
- If MINE: 💥 GAME OVER
  → ALL players lose their bets
  → Game ends immediately

Victory Condition:
- Reveal ALL safe cells (19 out of 25)
- ALL players win: bet × multiplier
- Multiplier ranges from 1.0x to 3.0x

EXAMPLE GAME:
-------------
Room: ABC123
Players: Alice ($100), Bob ($200)

Turn 1 (Alice): Clicks cell → Safe (2 mines nearby)
  Multiplier: 1.05x
  
Turn 2 (Bob): Clicks cell → Safe (0 mines nearby)
  Multiplier: 1.11x
  
Turn 3 (Alice): Clicks cell → Safe (1 mine nearby)
  Multiplier: 1.16x
  
... continues ...

Turn 15 (Bob): Clicks cell → 💣 MINE!
  Result: TEAM ELIMINATED
  Alice loses: -$100
  Bob loses: -$200
  
OR if they clear all safe cells:
  Result: TEAM VICTORY!
  Alice wins: +$300 (100 × 3.0x)
  Bob wins: +$600 (200 × 3.0x)

KEY POINTS:
-----------
✓ Cooperative team game
✓ One mistake = everyone loses
✓ Communication via chat is crucial
✓ Higher risk = higher multiplier
✓ Individual bets, shared outcome
